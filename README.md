# 🛡️ Hero's Tasks: RPG To-Do List

> **Turn your daily chores into an epic adventure.**

**Hero's Tasks** is a gamified task manager that transforms the mundane act of checking off a to-do list into a role-playing game experience. Earn Experience Points (XP) for completing tasks, level up, and tackle higher-priority quests to become a productivity legend.

## ✨ Features

* **⚔️ Gamified Progression**: Earn XP for every task completed. Watch your progress bar fill up and your Level increase!
* **⚖️ Priority System**:
  * 🟢 **Low Priority**: Easy quests (10 XP)
  * 🟠 **Medium Priority**: Standard quests (20 XP)
  * 🔴 **High Priority**: Boss-level quests (50 XP)
* **💾 Local Persistence**: Your Level, XP, and active quests are saved automatically to your browser's LocalStorage. You won't lose progress when you refresh.
* **🎨 Dark Mode UI**: A sleek, focused interface designed for late-night coding sessions.
* **⚡ Built with TypeScript**: Type-safe, scalable, and maintainable code.

## 🛠️ Tech Stack

* **Core Logic**: TypeScript
* **Structure**: HTML5
* **Styling**: CSS3 (Flexbox, CSS Variables, Animations)
* **Icons**: Font Awesome

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

You need **Node.js** and **npm** installed to use the TypeScript compiler.

* [Download Node.js](https://nodejs.org/)

### Installation

1. **Clone the repository** (or download the files):

    ```bash
    git clone [https://github.com/yourusername/heros-tasks.git](https://github.com/yourusername/heros-tasks.git)
    cd heros-tasks
    ```

2. **Install TypeScript globally** (if you haven't already):

    ```bash
    npm install -g typescript
    ```

3. **Compile the TypeScript code**:
    Run the following command in your terminal to generate the `main.js` file:

    ```bash
    tsc main.ts --target es6
    ```

4. **Launch the App**:
    Simply open `index.html` in your preferred web browser.

## 🎮 How to Play

1. **Accept a Quest**: Type a task into the input field.
2. **Set Difficulty**: Choose a priority (Low, Medium, or High). Higher priority = more XP!
3. **Complete Quests**: Click the Checkmark (✔) to turn in the quest.
4. **Level Up**: As you gain XP, your level increases. The amount of XP needed for the next level increases dynamically (scaling difficulty).
